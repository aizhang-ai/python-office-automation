# 表格批量处理工具（零依赖版）

把一堆乱七八糟的表格，按你写好的步骤一次性处理干净：合并、清洗、去重、排序、分组统计、按条件拆分。

---

## 你需要准备什么

| 项目 | 要求 |
|---|---|
| Python | 3.8 或以上（免费，安装时勾选 Add to PATH） |
| 其他软件 | **没有**。不用装 pip 包，不用装 Excel |
| 花费 | 0 元 |

> 处理的是 CSV 文件。**Excel 可以直接打开 CSV，也可以把 xlsx 另存为 CSV**（文件 → 另存为 → 选 CSV UTF-8）。

---

## 三步跑起来

**第 1 步**：把要处理的表格放进 `input` 文件夹（里面已经有 3 个示例文件，跑通后删掉换成你自己的）。

**第 2 步**：用记事本打开 `config.json`，改 `steps`（就是你要它做的步骤，从上到下依次执行）：

```json
"steps": [
  { "action": "merge",  "pattern": "*.csv" },
  { "action": "clean",  "columns": ["phone", "email", "date", "amount"] },
  { "action": "dedupe", "key": "phone", "keep": "first" },
  { "action": "sort",   "by": "amount", "order": "desc" },
  { "action": "group",  "by": "city", "sum": ["amount"], "count": ["phone"], "output": "汇总.csv" },
  { "action": "split",  "by": "city", "output_dir": "按城市" },
  { "action": "save",   "output": "result.csv" }
]
```

**第 3 步**：双击 `run.bat`。结果在 `output` 文件夹，处理报告在 `run-report.txt`。

不想写配置？执行 `python table_tool.py --init` 会生成一份模板。

## 六个动作的参数说明

| 动作 | 作用 | 参数 |
|---|---|---|
| `merge` | 把 input 文件夹里所有表合成一个 | `pattern`：文件匹配，如 `*.csv`、`华东*.csv` |
| `clean` | 清洗字段 | `columns`：要清洗的列名；留空 = 全部列 |
| `dedupe` | 去重 | `key`：按哪一列判重；`keep`：`first` 保留第一条 / `last` 保留最后一条 |
| `sort` | 排序 | `by`：按哪列；`order`：`asc` 升序 / `desc` 降序 |
| `group` | 分组统计 | `by`：按哪列分组；`sum`：要求和的列；`count`：要数非空个数的列；`output`：存成什么文件名 |
| `split` | 拆成多个文件 | `by`：按哪列的值拆；`output_dir`：子文件夹名 |
| `save` | 保存结果 | `output`：文件名 |

> `group` 和 `split` 的结果**单独存文件，不会破坏明细数据**，后面还能继续处理。

## clean 会自动做什么

| 列名里含这些字 | 处理方式 |
|---|---|
| phone / mobile / tel / 手机 / 电话 | 去掉所有非数字，只留纯数字（11 位以外会算作异常，但**保留原值**不删你的数据） |
| email / mail / 邮箱 | 去空格、转小写，格式不对的标为异常但保留 |
| date / time / 日期 / 时间 | `2026/9/1`、`2026.9.3`、`2026年9月2日`、`20260905` 统一成 `2026-09-03` 这种标准格式 |
| amount / money / price / 金额 / 价格 | 去掉千分位逗号和 ¥ $ 符号，变成纯数字（这样 Excel 里能直接求和） |
| 其他列 | 去掉多余空格和换行 |

异常值不会删掉，只是在报告里告诉你有几条，方便你自己核对。

## 常见问题

**Q：我的表是 xlsx，能用吗？**
Excel 里「另存为 → CSV UTF-8（逗号分隔）」就行。工具不会改你原来的 xlsx 文件。

**Q：中文乱码？**
配置里 `"encoding": "utf-8-sig"` 就能让 Excel 正常显示中文。如果你的文件是 GBK 老格式，改成 `"gbk"`。

**Q：处理错了能恢复吗？**
工具**从不修改 input 文件夹里的原文件**，所有结果都写在 output 里。放心试。

**Q：能处理多少行？**
几万行没问题。几十万行以上会慢一些，但仍然可用。

**Q：我的数据会上传吗？**
不会。全部在你自己电脑上跑，没有任何联网请求。

**Q：去重时两行数据不一样，留哪条？**
默认留先出现的那条（`keep: first`）。想留最新的改成 `last`。
