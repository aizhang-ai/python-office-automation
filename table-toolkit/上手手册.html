表格批量处理工具箱

按这个页面做一遍，5 分钟能跑起来。不用懂编程，会复制粘贴就行。

先说一句安心的话：这个工具不会改动你的原文件。所有结果都输出到 output 文件夹，你放进去的原始表格一个字节都不会变。

第 1 步 · 装 Python（装过就跳过）

1.1 下载 打开 python.org/downloads/windows， 点中间那个大按钮下载。
1.2 安装（这一步别漏） 双击安装包，一定要先勾选最下面那个 "Add python.exe to PATH"，再点 "Install Now"。
不勾这个，后面双击 bat 会一闪而过没反应。勾了就没事。
1.3 验证 按 Win + R，输入 cmd 回车，在黑窗口里输入 python --version 回车。 看到 Python 3.x.x 就成了。看到"不是内部或外部命令"说明上一步没勾，重装一次即可（可以覆盖安装）。

第 2 步 · 放文件

把你下载的这个文件夹打开，里面有个 input 文件夹。把要处理的表格放进去。

要点：必须是 CSV 格式。Excel 的 .xlsx 直接放进去读不了。
转换方法：用 Excel 打开你的表 → 左上角「文件」→「另存为」→ 保存类型选 「CSV UTF-8 (逗号分隔)」 → 存到 input 文件夹。 每张表都这样存一次。

放几张都行，工具会把它们按表头自动对齐合并成一张。

第 3 步 · 改配置（告诉它你要干什么）

用记事本（或 VS Code）打开 config.json，你会看到类似这样：

{
  "input_dir": "input",
  "output_dir": "output",
  "encoding": "utf-8-sig",
  "steps": [
    { "action": "merge",  "pattern": "*.csv" },
    { "action": "clean",  "columns": ["phone", "email", "date", "amount"] },
    { "action": "dedupe", "key": "phone", "keep": "first" },
    { "action": "sort",   "by": "amount", "order": "desc" },
    { "action": "group",  "by": "city", "sum": ["amount"], "output": "汇总.csv" },
    { "action": "save",   "output": "result.csv" }
  ]
}

steps 就是"要做的动作清单"，从上往下依次执行。不需要的步骤直接删掉那一行就行。

动作干什么写法示例
merge把 input 里所有表合成一张{"action":"merge","pattern":"*.csv"}
clean规范化：手机号去空格横线、邮箱转小写、日期统一成 2026-09-01、金额去掉千分位和￥{"action":"clean","columns":["手机","金额"]}
dedupe按某一列去重，重复的行去掉{"action":"dedupe","key":"手机号","keep":"first"}
sort按某一列排序{"action":"sort","by":"金额","order":"desc"}
group按某列分组求和/计数，结果另存一个文件，不动主表{"action":"group","by":"城市","sum":["金额"],"count":["手机号"],"output":"汇总.csv"}
split按某列的值拆成多个文件{"action":"split","by":"城市","output_dir":"按城市"}
save保存最终结果（一般放最后一步）{"action":"save","output":"result.csv"}
改的时候注意两件事：
  • 列名必须和你表格里的表头一模一样（多一个空格都不行）。
  • 删掉某行时，注意上一行末尾的逗号也要删掉，否则会报错。最简单的办法：保持最后一行没有逗号。

第 4 步 · 跑

双击 run.bat。黑窗口会刷几行字然后停住，按任意键关掉。

然后打开 output 文件夹看结果：result.csv 是主结果，汇总.csv 是分组结果（如果配了 group）。

不喜欢双击？也可以在文件夹里按 Shift + 右键 →「在此处打开命令窗口」，输入 python table_tool.py 回车。这样窗口不会自动关，报错看得更清楚。

出问题了？先看这里

双击 bat 一闪而过，什么都没有

Python 没装好，或者安装时没勾 "Add to PATH"。回到第 1 步验证。改用第 4 步里说的命令行方式运行，能看到具体报错。

输出的表中文全是乱码

把 config.json 里的 "encoding" 改成 "gbk"（原来是 "utf-8-sig"），再跑一次。

反过来也成立：如果改成 gbk 反而乱了，那就还是用 "utf-8-sig"。老版 Excel（2016 以前）通常要 gbk。

报错说找不到某一列

列名和表头不一致。打开你的 CSV 看第一行，把 config.json 里的名字改成一模一样的，注意有没有多余空格。

日期没被规范化

目前能识别这几种写法：2026/9/1、2026年9月2日、2026.9.3、20260905、2026-09-04。 如果你的日期是别的写法（比如"9月1日"没有年份），工具会原样保留、不会破坏数据。需要支持别的写法可以告诉我。

金额那一列还是带逗号

确认 clean 那一步的 columns 里包含了金额列的列名。如果列名不含"金额/价格/价/钱/amount/price"这类字， 工具可能认不出它是金额——把列名加进 columns 即可。

这个工具不会做的事

  • 不会改你的原文件——所有结果输出到 output，input 里的一动不动。
  • 不会上传任何数据——全在你自己电脑上跑，没有联网，也没有服务器。
  • 不会猜你的业务规则——去重保留哪条、分组按哪个字段，都是你在 config 里明说的，它不替你决定。
