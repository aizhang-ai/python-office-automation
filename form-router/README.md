# 订单 / 表单自动处理与归档（零依赖版）

表单进来没人及时分派、线索会凉。这个工具把「收表单 → 清洗 → 校验 → 分派 → 编号 → 归档 → 出报告」串成一条线，双击就跑完。

适用：电商订单、官网留资表单、报名表、询盘、售后工单、加盟申请——任何能导出成 CSV 的表单。

---

## 你需要准备什么

| 项目 | 要求 |
|---|---|
| Python | 3.8 或以上（免费，安装时勾选 Add to PATH） |
| 其他软件 | **没有**。不用装 pip 包，不用装 Excel，不用服务器 |
| 花费 | 0 元 |

> 处理的是 CSV 文件。**Excel 可以直接把 xlsx 另存为 CSV**（文件 → 另存为 → CSV UTF-8）。
> 金数据 / 腾讯问卷 / 表单大师 / 麦客 CRM 后台都能导出 CSV，导出来直接扔进 `inbox` 就行。

---

## 三步跑起来

**第 1 步**：把表单导出的 CSV 放进 `inbox` 文件夹（里面已有 2 个示例文件，共 15 行，跑通后删掉换成你自己的）。

**第 2 步**：用记事本打开 `config.json`，改两处：
- `required_fields` —— 哪些字段必填（缺了会被挑出来，不会混进正常订单）
- `rules` —— 分派规则，**从上往下匹配，命中第一条就停**

**第 3 步**：双击 `run.bat`。

结果在哪：
- `output/orders-all.csv` —— 全部有效订单总表（带编号、分类、负责人、优先级）
- `output/异常待处理.csv` —— 缺必填的行，单独一张，写了缺什么
- `output/daily-report.txt` —— 当日处理报告
- `archive/日期/分类.csv` —— 按分类归档，如 `大客户.csv`、`华东区.csv`
- `archive/日期/原始文件/` —— 当天收到的原始 CSV 备份

原始文件**全程不被修改**。

## 分派规则怎么写

```json
{
  "name": "大客户",
  "priority": "high",
  "owner": "负责人A",
  "match": [
    { "field": "amount", "op": "gte", "value": 10000 }
  ]
}
```

支持的条件运算符：

| op | 含义 | 例子 |
|---|---|---|
| `gte` / `gt` / `lte` / `lt` | 数值比较 | 金额 ≥ 10000 |
| `equals` | 完全相等 | 渠道 = 官网 |
| `contains` | 包含 | 产品名含「维修」 |
| `in` | 属于列表 | 城市 in 上海/杭州/南京/苏州 |
| `regex` | 正则匹配 | 手机号 `^1[3-9]\d{9}$` |
| `not_empty` | 非空 | 备注非空（有人留言的优先处理） |

- 一条规则里的多个条件是**「且」**关系，全满足才命中。
- `match` 写成 `[]` 的规则是**兜底规则**，放最后一条，保证每条数据都有归属。
- 规则顺序即优先级：想让「售后咨询」优先于「华东区」，就把它写在前面。

## 自动清洗什么

| 列名含 | 处理 |
|---|---|
| phone / 手机 / 电话 | `138 0013 8000`、`139-0013-9000`、`+86-137-0013-7000` → `13800138000` |
| email / 邮箱 | `ZhangWei@QQ.com ` → `zhangwei@qq.com`（去空格、转小写） |
| date / 日期 | `2026/9/1`、`2026年9月2日`、`2026.9.3`、`20260905` → `2026-09-01` |
| amount / 金额 / 价格 | `"12,800"`、`¥1200` → `12800`（Excel 里能直接求和） |
| 其他列 | 去掉多余空格和换行 |

## 去重

默认按 `phone + product` 判重（`config.json` 的 `dedupe.keys` 可改）。
同一手机号下单同一产品多次，只保留一条——`keep` 设为 `last` 留最新，`first` 留最早。

## 编号

自动生成 `ORD-20260923-0001` 这种编号（`id_prefix` 可改成你自己公司的前缀），并写入 `process_date` 处理日期。

## 群机器人推送（可选，默认关闭）

把 `config.json` 里 `notify.enabled` 改成 `true`，填上群机器人 webhook 地址：

```json
"notify": { "enabled": true, "type": "wecom", "webhook": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=..." }
```

`type` 支持 `wecom`（企业微信）、`feishu`（飞书）、`dingtalk`（钉钉）。
用的是各平台**官方提供的群机器人 webhook**——只往群里推消息，不读取任何聊天内容。
推送失败只会在日志里记一行，不影响文件正常产出。

## 定时运行

**Windows**：任务计划程序 → 创建基本任务 → 启动程序，程序填 `run.bat` 完整路径，起始位置填本文件夹路径。
或命令行：
```
schtasks /create /tn "表单处理" /tr "D:\tools\form-router\run.bat" /sc daily /st 09:00
```

**Linux / macOS**：`crontab -e`
```
0 9 * * * cd /path/to/form-router && /usr/bin/python3 form_router.py
```

每天定时跑一次，`inbox` 里放进新表单，第二天早上报告就出来了。

## 常见问题

**Q：试跑会改我的文件吗？**
`python form_router.py --dry-run` 只打印报告，不写任何文件，可以放心先试。

**Q：配置写错了怎么办？**
`python form_router.py --init` 会重新生成一份默认配置模板（会覆盖现有 config.json）。

**Q：中文乱码？**
配置里 `"encoding": "utf-8-sig"` 让 Excel 正常显示中文；老系统导出的 GBK 文件改成 `"gbk"`。工具也会自动尝试多种编码读取。

**Q：我的数据会上传吗？**
不会。全部在你自己电脑上跑。唯一可能的联网动作是你自己开启的群机器人推送。

**Q：能处理多少条？**
几千条没问题；几万条也能跑，稍慢。

**Q：想按渠道分派，但我的表没有「渠道」列？**
导出的文件名就带着来源，每行都有 `__source__` 列标明来自哪个文件，可以直接写规则用。
