# 每日经营数据简报机器人

读你本地导出的 CSV（订单、销售、门店流水都行），自动算出当天核心指标、环比、分组构成、TOP 榜和异常告警，
生成一份**能直接复制到群里**的日报文本，可选推送到企业微信 / 钉钉 / 飞书群机器人。

**纯 Python 标准库，零 pip 安装。原始数据全程只读，不会改动你的任何源文件。**

---

## 一、它到底帮你省了哪一步

如果你的日常是下面这样，这个工具就是给你做的：

> 每天（或每周一）有人从后台导出一张表 → 打开 Excel → 拉透视表 → 算总额、算环比、找 Top →
> 复制数字到微信/钉钉里发一句「今日销售额 xx，环比 +x%」→ 还要自己判断今天是不是掉得不对劲。

这个工具把上面这一串变成一条命令：把 CSV 丢进 `input/`，跑一次，`output/daily-brief.txt` 里就是成品，
复制粘贴发出去。要全自动就配个计划任务，每天定时跑，直接推到群里。

---

## 二、三步跑起来

### 第 1 步：装好 Python（已装可跳过）

到 python.org 下载安装，**安装时务必勾选 `Add Python to PATH`**（这是绝大多数人卡住的地方）。
装完打开命令提示符，输入 `python --version` 能看到版本号就说明好了。

### 第 2 步：把数据放进 input

- 需要一个 CSV 文件（Excel 里「另存为 → CSV UTF-8」）
- 至少要有一列**日期**、一列**金额**
- 文件名、列顺序不限；可以一次放很多个文件，会自动合并

想先试试有没有效果，不用准备数据：

```
python tests/make_testdata.py     # 生成 5 天的演示数据（含脏数据）
python daily_brief.py --dry-run   # 只打印，不写文件
```

### 第 3 步：改配置、跑

双击 `run.bat` 最省事（先试算、确认后才正式生成）。
也可以命令行：

```
python daily_brief.py                     # 正式跑，写 output/
python daily_brief.py --date 2026-09-23   # 指定报告哪一天
python daily_brief.py --push              # 顺便推到群里
```

## 三、config.json 每一项怎么填

| 字段 | 填什么 | 不填会怎样 |
|---|---|---|
| `input_dir` | 数据目录，默认 `input` | 读不到数据 |
| `output_dir` | 输出目录，默认 `output` | 自动创建 |
| `file_pattern` | 匹配哪些文件，默认 `*.csv` | 可写 `sales_*.csv` 只挑销售表 |
| `recursive` | 是否进子文件夹，默认 `true` | — |
| `date_field` | **你的日期列名** | 写错就分不出「今天」 |
| `amount_field` | **你的金额列名** | 写错会报「缺列」 |
| `group_fields` | 按哪些列分组看构成，如 `["city","channel"]` | 空数组就不出分组段 |
| `top_field` | 排 TOP 榜用哪一列，如 `order_id` / `product` | 留空不出 TOP 段 |
| `top_n` | TOP 几条，默认 5 | — |
| `compare_mode` | `previous_day`（比上一天）/ `same_day_last_week`（比上周同天） | — |
| `alerts.drop_pct` | 跌超这个百分比就告警，如 `20` | 填 `0` 或删掉即关闭 |
| `alerts.rise_pct` | 涨超这个百分比就告警（异常大涨也值得看一眼） | 同上 |
| `alerts.min_amount` | 日销售额低于这个数告警 | `0` = 关闭 |
| `alerts.min_orders` | 单数低于这个数告警 | `0` = 关闭 |
| `webhook.enabled` | 是否推送，默认 `false` | — |
| `webhook.type` | `wecom` / `dingtalk` / `feishu` | — |
| `webhook.url` | 群机器人的 Webhook 地址 | 留空则跳过推送，不影响其他功能 |

**关于群机器人**：只用平台官方提供的「群机器人 Webhook」，你在群里点几下就能拿到一个地址。
本工具不会登录你的企业微信、不会读聊天记录、不会替你回消息——只往那个地址发一条文本。
没有地址也能正常用，把生成的 txt 手动复制进群是一样的。

## 四、它认得哪些脏数据

真实导出的表从来不干净，这些情况都已经处理过：

| 情况 | 处理 |
|---|---|
| 金额 `1,200.50` / `¥1,200` / ` 1200 ` / `(380)` | 全部正确解析，`(380)` 识别为 -380（退货） |
| 日期 `2026-09-24`、`2026/9/24`、`2026.9.24`、`20260924`、`2026年9月24日`、Excel 序列号 `46268` | 五种常见写法 + Excel 序列号都能解析 |
| 金额列是空的 | 跳过该行，不计入总额和单数 |
| 分组字段是空的 | 归入 `(未填)`，不丢钱 |
| 文件编码 UTF-8 / UTF-8-BOM / GBK | 自动尝试三种编码 |
| 某一列不存在 | 该文件被跳过，并在报告末尾列出原因（不会整个崩掉） |

## 五、输出文件

| 文件 | 内容 |
|---|---|
| `output/daily-brief.txt` | **主产物**，纯文本日报，可直接复制到群 |
| `output/daily-brief.md` | Markdown 版，可贴到飞书/语雀/公众号后台 |

| `output/history.csv` | 每天一条累计记录，跑得越久走势越完整 |

## 六、常见问题

**Q：跑出来金额是 0 / 行数 0？**
看报告末尾的「被跳过的文件」，多半是 `amount_field` 或 `date_field` 和你的列名对不上。
列名要一模一样，包括大小写。

**Q：中文乱码？**
CSV 请用 Excel 的「CSV UTF-8(逗号分隔)」格式另存。本工具也会自动尝试 GBK，但 UTF-8 最稳。

**Q：想每天自动跑？**
Windows：任务计划程序 → 创建基本任务 → 触发器「每天」→ 操作「启动程序」→
程序填 `python.exe` 的完整路径，参数填 `daily_brief.py --push`，起始位置填本文件夹路径。

**Q：多个门店 / 多个店铺的数据混在一起？**
两种办法：① 丢进 `input` 的不同子文件夹，用 `group_fields` 拆；② 直接按店分几次跑，每份一个 config。

**Q：能读 Excel 的 .xlsx 吗？**
不能直接读。Excel 里「文件 → 另存为 → CSV UTF-8」就行。这是为了保持零安装——读 xlsx 要装第三方库。

## 七、实测记录（2026-09-24，Windows + Python 3.13.12）

造了 5 天、69 行演示数据，故意混入：金额带千分位/人民币符号/前后空格/括号负数、
日期 5 种写法、5 行空金额、5 行缺城市，第 4 天基准额腰斩。

真实运行结果：

- 读到 64 行有效数据（5 行空金额被跳过，与预期一致）
- 报告日 2026-09-24：销售额 ¥14,112.25 / 14 单 / 客单价 ¥1,008.02，环比 +117.7%（对比 2026-09-23 的 ¥6,482.67 / 8 单）
- 分组：city 拆出 5 个城市 + `(未填)` 一项（已把缺城市的那 520 元兜住）；channel 拆出门店/外卖/电商/团购
- 告警：2026-09-23 那天触发「销售额较上一周期下降 50.7%」（阈值 -20%）；2026-09-24 触发「上涨 117.7%」（阈值 +50%）
- 走势段一次跑出 5 天（2026-09-20 ~ 09-24），不是只有当天
- 输出 5 个文件全部生成；`input/` 下 5 个源文件字节数与时间戳**全程未变**

完整原始输出见 `tests/sample-report.txt`。

## 八、边界与说明

- 数据是**只读**的，任何情况下都不会改、不会删、不会移动你的原始文件。
- 不联网、不登录、不抓取。只有你填了 Webhook 地址并加了 `--push` 时，才会向外发一次文本。
- 不出任何「预计提升 xx%」之类的承诺——它只是把你自己的数据算清楚。
