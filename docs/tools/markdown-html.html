支持哪些语法

  • 标题 # ~ ######
  • 粗体 **x**、斜体 *x*、删除线 ~~x~~
  • 行内代码 `x`、围栏代码块 ```
  • 无序列表 - * +、有序列表 1.
  • 表格（| 分隔，第二行 |---|）
  • 引用 >、分割线 ---
  • 链接 [文字](地址)、图片 ![说明](地址)
  • 标题自动加 id 锚点，可做目录跳转
  • HTML 特殊字符自动转义，不会破坏页面
  • 暂不支持：嵌套列表、脚注、任务列表复选框、自定义容器
