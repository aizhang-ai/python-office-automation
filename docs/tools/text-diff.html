什么情况下用得上

  • 合同/协议改了一版，要确认对方到底动了哪几条
  • 配置文件改完上线前，和上一版对一遍有没有改错地方
  • 两份名单、两份报价单，看差在哪几行

这是逐行对比：一行里改了一个字，会算成「删掉旧行 + 新增新行」。 行数很多（几千行以上）时会自动降级为整段替换，保证不卡死浏览器。
