URL 编码 / 解码

中文和特殊字符转成 %E4%B8%AD 这种能在地址栏里安全传输的形式，也能还原回来。 顺手把 ?a=1&b=2 拆成能改的键值对，改完再拼回去。不上传

① 文本 ↔ URL 编码

② 查询参数 ↔ 键值对

粘贴一整条网址或一段 a=1&b=2，点「拆开」把它拆成一行一个参数； 改完之后点「拼回去」重新组装。重复的参数名会原样保留，不会丢。

③ 批量（一行一个）

有很多条要转的时候用这个，一行一条，一次全转完。

几个常踩的坑

  • 编码整个网址，还是只编码参数值：这是最常搞混的一点。 编码参数值时，/ : ? & = 都要转义，否则会破坏网址结构； 编码整条网址时则必须保留它们。本工具用「保留 / : ? & = #」这个开关区分。
  • 空格：%20 还是 +：网址里标准写法是 %20； 但 HTML 表单提交（application/x-www-form-urlencoded）会写成 +。 发给后端接口前先确认它按哪种解析，两边不一致就会解出加号。
  • 编两次会解不回来：张三 编一次是 %E5%BC%A0%E4%B8%89， 再编一次 % 本身会变成 %25。如果你发现解出来的还是一串百分号，就是被编了两次。
  • 报错「URI malformed」：说明这串百分号编码不完整（比如只截到了 %E5 半个字）， 或者里面混了没转义的 %。先确认原文有没有被截断。
  • URL 编码不是加密：它只是转义，任何人都能还原。不要用它"保护"手机号、身份证号这类信息。
