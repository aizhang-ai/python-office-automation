几个常踩的坑

  • 中文乱码：浏览器自带的 btoa() 只认单字节，中文会直接报错或变乱码。本工具先转成 UTF-8 字节再编码，所以中文、emoji 都没问题。
  • 标准 vs URL-safe：标准用 + /，URL-safe 用 - _。放进 URL 或文件名里一定要用 URL-safe，否则 + 会被当成空格。
  • 末尾的等号：那是补齐用的填充符，不是数据。有些系统要求去掉，有些要求保留，按对方的要求勾。
  • 长度会变长：Base64 大约比原文长 1/3。一段 1MB 的图片会变成约 1.33MB 的文本。
  • 它不是加密：Base64 只是编码方式，任何人都能解回来。别拿它存密码或敏感信息。
