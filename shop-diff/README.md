# 多店铺商品信息核对与差异报告

同一个 SKU，总店卖 ¥199，京东店还挂着 ¥259——这种事不核对就一直挂着。

这个工具读你从各个店铺后台**导出的 CSV**，按商品编码对齐，逐字段比对价格、库存、标题、上下架状态，
把「改了价的、库存对不上的、这家有那家没有的」全部列出来，出一份能直接发群里的报告和三张表。

- 纯 Python 标准库，**不用 pip 装任何东西**
- **不改你的原始文件**，所有结果写到 `output/`
- **不联网抓任何平台数据**，只读你自己导出的文件（不做爬虫、不绕登录）
- 表头名字不一样没关系，config 里配个别名就能对上

---

## 三步跑起来

**第 1 步：装 Python**（已装可跳过）
去 https://www.python.org/downloads/ 下载，安装时勾选 **Add Python to PATH**。

**第 2 步：把各店铺导出的表放进 `input` 目录，改 `config.json`**

```json
"stores": [
  { "name": "总店",   "file": "input/store_a.csv" },
  { "name": "京东店", "file": "input/store_b.csv" }
]
```

**第 3 步：双击 `run.bat`**

跑完打开 `output\latest-report.txt`。

## config.json 字段说明

| 字段 | 默认 | 说明 |
|---|---|---|
| `stores` | — | 要核对的表，`name` 是显示名，`file` 是路径（相对路径基于本目录） |
| `key` | `sku` | 用来对齐的主键列名，一般是商品编码 / SKU |
| `compare_fields` | price/stock/title/status | 要比对的字段 |
| `numeric_fields` | price/stock | 哪些字段按数字比（会解析 `¥1,200` 这类写法） |
| `tolerance` | 0.01 | 数值差小于这个值算一致 |
| `mode` | `baseline` | `baseline`＝第 1 家当基准，其余逐一比对；`all_pairs`＝所有店两两比对 |
| `top_n` | 10 | 报告里价格差异 TOP 显示几条 |
| `max_alert_diff` | 1 | 差异达到多少处才推送告警 |
| `trim` | true | 自动去掉值前后的空格（SKU 前后带空格也能对上） |
| `ignore_case` | false | 主键比对时忽略大小写 |
| `column_alias` | 见下 | 表头别名映射 |
| `alert` | 关闭 | 告警推送配置 |

### 表头名字不一样怎么办

配 `column_alias`，左边是**你表里的名字**，右边是**标准字段名**（`sku` / `price` / `stock` / `title` / `status`）：

```json
"column_alias": {
  "商品编码": "sku",
  "销售价": "price",
  "库存量": "stock",
  "商品名称": "title",
  "上下架": "status"
}
```

默认已经内置了一组常见别名（`商品编号`、`SKU码`、`售价`、`库存`、`商品名称`、`状态` 等），
不在这组里的自己加一行就行。**没配映射的列名会原样保留**，如果你直接拿 `key` 指向它也能用。

### 告警推送

默认关闭。要开启：在企业微信/钉钉/飞书群里加一个**群机器人**，拿到官方 Webhook 地址填进来：

```json
"alert": {
  "enabled": true,
  "type": "wecom",
  "webhook": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx"
}
```

`type` 填 `wecom`（企业微信）/ `dingtalk`（钉钉）/ `feishu`（飞书）。

> 这是平台**官方开放**的单向推送接口，只是往群里发一条文本。
> 本工具不会也不去读取、控制任何聊天客户端。

## 命令行用法

```
python shop_diff.py                      按 config.json 跑一次
python shop_diff.py --top 20             报告里价格差异 TOP 显示 20 条
python shop_diff.py --no-alert           本轮不推送
python shop_diff.py --config D:\my\cfg.json
python shop_diff.py --out D:\my\out      结果写到别的目录
```

想每天自动跑：把 `run.bat` 的快捷方式放进「启动」目录，或用 Windows 任务计划程序每天定时执行
`python shop_diff.py`（在本目录下执行）。

## 本机实测记录

环境：**Windows + Python 3.13.12**，未安装任何第三方包。

造了两份「故意对不上」的演示表（`python tests/make_testdata.py` 可重现）：
总店 40 个 SKU（含 1 行缺主键、1 个重复编码），京东店 39 个（文件用 **GBK** 存，验证编码自动探测），
故意埋了 6 处改价、1 处对方价格为空、4 处库存不一致、2 处标题不一致、1 处状态不一致、
只在总店有 5 个、只在京东店有 4 个，金额写成 `¥1,010.00`、`1,020.00`、`1020` 三种，库存写成 `101件`。

**47 项断言全部通过**，真实输出（`output/latest-report.txt`）：

```
【总店】 vs 【京东店】
一、规模   基准 40 个 / 比对方 39 个 / 共有 35 个
二、差异   有差异的 SKU 14 个（占共有 40.0%），共 14 处
           price 不一致 7 处
           stock 不一致 4 处
           title 不一致 2 处
           status 不一致 1 处
三、价格差异 TOP 6
           S003   ¥1,030 -> ¥1,330   差 +300.00  (+29.1%)
           S001   ¥1,010 -> ¥1,110   差 +100.00  (+9.9%)
           S002   ¥1,020 -> ¥1,070   差 +50.00  (+4.9%)
           ...
四、只在【总店】有（5 个）—— 对方疑似未上架或编码不一致
五、只在【京东店】有（4 个）—— 基准方疑似漏了或已下架
六、数据质量
   总店：跳过 1 行（缺主键）
   总店：主键重复 1 个，已取第一条
```

同时验证：
- 编码探测：UTF-8-BOM 与 GBK 两种文件都能正确读出
- 金额解析：`¥1,299.00` → 1299.0、`(380)` → -380、`120件` → 120、`12.5%` → 12.5、中文 → None
- SKU 前后带空格（` S020 `）能正确对齐，不会被误判成「只有一方有」
- 两份源 CSV 的**字节数与修改时间全程未变**
- 价格差异 TOP 按差额绝对值排序（最大的是 S003 +300）
- `all_pairs` 模式：3 个店铺产出 3 个对比对
- 告警：未开启 / webhook 为空时不产生网络请求；差异未达阈值时不告警

完整样例见 `tests/sample-report.txt`。

## 常见问题

**双击 run.bat 一闪就没了？**
多半是没装 Python 或没勾 Add Python to PATH。cmd 里敲 `python --version` 试一下。

**提示找不到文件？**
`file` 写相对路径时是相对**本目录**的。把 CSV 放进 `input` 目录最省事。

**Excel 的 .xlsx 能读吗？**
不能直接读。在 Excel 里「另存为 → CSV UTF-8（逗号分隔）」再放进 `input`。
（.xlsx 需要装第三方库才能解析，那就破坏了"零安装"，所以不做。）

**两个表主键格式不一样（一个有横线一个没有）怎么办？**
先在你自己的表里统一。工具只做**去空格**和可选的**忽略大小写**，不会猜编码规则——猜错了会给出错误结论，比不做更糟。

**差异太多报告看不过来？**
看 `output/diff-detail.csv`，用 Excel 打开按字段筛选。报告只显示 TOP N。

## 要定制？

标准版能做的是：**两个/多个导出的表 → 对齐 → 逐字段比对 → 报告 + CSV + 告警**。

定制版可以做：每日定时跑并自动推送、按你的规则判断「该改哪个」（比如以低价为准、
以库存少的为准）、生成可直接导入后台的修正表、多平台编码互相映射、历史差异追踪看趋势。
